# EVM Project Tool 0.2.0

## Resumen

Actualización del dashboard frontend: selector de idioma Español/English persistente en la sesión, siglas EVM invariables en inglés con nombre localizado, tooltips accesibles (nombre, descripción, fórmula) e interpretación CPI/SPI derivada en el cliente a partir del valor numérico (sin usar `cpi_interpretation`/`spi_interpretation` del API).

Spec `evm-project-tool-frontend` Fase 5: 21/21 tareas. AUDIT ciclo 3: **PASA_CON_OBSERVACIONES**. E2E `docker compose up --build` en `apps/infrastructure/`: **PASA** (db healthy, migrate exit 0, API `/api-docs` y `/api/v1/projects` HTTP 200, SPA `:8080` HTTP 200). UI en navegador no ejercitada (Browser MCP sin pestaña).

## Cambios

### frontend (`evm-project-tool-frontend`) — PR #12 (develop)

- i18n propio (React Context): diccionarios `es`/`en`, `I18nProvider`, `useI18n`, persistencia `sessionStorage` clave `evm_locale`.
- `LanguageSwitcher` ES|EN en cabecera; re-render sin recargar la página.
- Catálogo de indicadores EVM (`evmIndicatorsCatalog.ts`): código inglés fijo + nombre/descripción/fórmula.
- `Tooltip` reutilizable (hover, foco de teclado, Escape, `role="tooltip"`, `aria-describedby`).
- Interpretación CPI/SPI local (`evmInterpretation.ts`); componentes de presentación no leen los strings del API.
- Strings visibles de la UI pasan por `t()`.
- Tests de humo Vitest: `LanguageSwitcher`, `Tooltip`, `evmIndicatorsCatalog`, `CpiSpiBadge`.
- AUDIT ciclo 3: **PASA_CON_OBSERVACIONES** (R-02/R-06 verificación visual pendiente; R-07 tooltip nativo Recharts en barras).
