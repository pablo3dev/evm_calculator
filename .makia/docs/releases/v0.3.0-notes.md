# EVM Project Tool 0.3.0

## Resumen

Corrección de UI: las siglas EVM se muestran solo en inglés en superficie (consolidados, tabla, badges y gráfica). El nombre en el idioma activo, la descripción y la fórmula aparecen en un tooltip reutilizable al hover o foco. El botón Eliminar de la tabla vuelve a ser legible.

Spec `evm-project-tool-frontend` Fase 6: 2/2 tareas. Vitest / lint / build: **PASA**. E2E `docker compose up --build` en `apps/infrastructure/`: **PASA** (db healthy, migrate exit 0, API `/api-docs` y `/api/v1/projects` HTTP 200, SPA `:8080` HTTP 200).
