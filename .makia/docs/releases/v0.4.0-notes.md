# EVM Project Tool 0.4.0

## Resumen

La tabla de actividades se dimensiona al ancho del contenido. Los badges CPI/SPI (sigla + ícono + interpretación) quedan en una sola línea; si no caben en el viewport, el contenedor hace scroll horizontal en lugar de partir el texto carácter a carácter.

Spec `evm-project-tool-frontend` Fase 7: 1/1 tareas. Vitest / lint / build: **PASA**. E2E `docker compose up --build`: **PASA** (SPA `:8080` y API `:8000` HTTP 200).
