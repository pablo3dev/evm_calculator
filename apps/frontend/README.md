# EVM Project Tool — Frontend

React + TypeScript SPA built with Vite.

## Environment

| Variable            | Description                       | Default (dev)                  |
| ------------------- | --------------------------------- | ------------------------------ |
| `VITE_API_BASE_URL` | Base URL for the backend REST API | `http://localhost:8000/api/v1` |

Create `.env.local` to override values locally (see `.gitignore`).

## Scripts

```bash
npm run dev      # start dev server
npm run build    # typecheck + production build
npm run lint     # ESLint
npm run format   # Prettier write
```
